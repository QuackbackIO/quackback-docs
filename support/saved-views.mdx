# Save inbox views

If you filter the same way every morning, stop rebuilding it by hand. A saved view stores a filter combination and a sort order under a name in the [inbox sidebar](/support/inbox).

## Create a view

From the inbox, build the filter you want, then save it: pick from status, priority, assignee, team, tag, source, waiting state, conversation or ticket, ticket type, ticket category, or ticket stage, up to 15 rules per view, plus a sort order (recent, oldest, created, waiting, priority, or SLA).

<Note>
A saved view stores the filter rules, not a live snapshot. Every time you open it, it re-runs the filter against the current inbox, so it always reflects what's actually there right now.
</Note>

## Pin a view

Pin a view to keep it at the top of your own sidebar. Pinning is personal: pinning a view for yourself doesn't change anyone else's sidebar.

## Share a view

A view is shared with your whole workspace by default, so any teammate can use it. Turn off sharing to keep a view private to you.

<Tip>
Build a small set of shared views your whole team recognizes ("Urgent + Unassigned", "Waiting on us") rather than everyone building their own from scratch.
</Tip>
