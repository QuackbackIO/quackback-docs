# Install the widget

Paste a snippet or install the npm package. The launcher appears in anonymous mode as soon as `init` runs — no signing secret needed. Call [identify](/widget/identify-users) later if you want signed-in activity to attach to a real person.

Tabs, colors, and launcher copy come from **Admin → Settings → Widget**.

## Embed the snippet

1. Go to **Admin → Settings → Widget → Install**
2. Copy the launcher snippet (identify is optional)
3. Paste it before the closing `</body>` tag
4. Turn on **Show on your website** in Widget settings

The snippet looks like this (your instance URL is pre-filled in admin):

```html
<script>
  (function(w,d){if(w.Quackback)return;w.Quackback=function(){
  (w.Quackback.q=w.Quackback.q||[]).push(arguments)};
  var s=d.createElement("script");s.async=true;
  s.src="https://feedback.example.com/api/widget/sdk.js";
  d.head.appendChild(s)})(window,document);

  Quackback("init");
</script>
```

Replace `https://feedback.example.com` with your Quackback instance URL.

The snippet creates a command queue, then loads the SDK. Calls you make before the script loads replay automatically. Script-tag installs can omit `instanceUrl` — the SDK reads it from `sdk.js`.

<Note>
Turn on **Show on your website** in **Admin → Settings → Widget** or the launcher stays hidden even after the snippet loads.
</Note>

## Install with npm

```bash
npm install @quackback/widget
```

```js
import { Quackback } from "@quackback/widget";

Quackback.init({ instanceUrl: "https://feedback.example.com" });
```

`instanceUrl` is required for the npm package. Vue, Svelte, Angular, and Solid can call `Quackback` the same way.

### React

```tsx
import { useEffect, useState } from "react";
import { useQuackbackInit, useQuackback, useQuackbackEvent } from "@quackback/widget/react";

function App() {
  const [ssoToken, setSsoToken] = useState<string | undefined>();

  useEffect(() => {
    fetch("/widget-token")
      .then((r) => r.json())
      .then(({ token }) => setSsoToken(token))
      .catch(() => {});
  }, []);

  useQuackbackInit({
    instanceUrl: "https://feedback.example.com",
    identity: ssoToken ? { ssoToken } : undefined,
  });

  useQuackbackEvent("post:created", (post) => {
    analytics.track("feedback_submitted", { postId: post.id });
  });

  return <Layout />;
}

function FeedbackButton() {
  const qb = useQuackback();
  return (
    <button onClick={() => qb.open({ view: "new-post" })}>Feedback</button>
  );
}
```

No provider is required. The hooks wrap the singleton SDK.

<Tip>
Fetch `ssoToken` from your backend. Do not pass raw `id` or `email` from the browser. See [Identify users](/widget/identify-users).
</Tip>

## Configure with init options

Script tag:

```js
Quackback("init", {
  placement: "left",
  defaultBoard: "feature-requests",
  locale: "fr",
});
```

npm:

```js
Quackback.init({
  instanceUrl: "https://feedback.example.com",
  placement: "left",
  defaultBoard: "feature-requests",
  locale: "fr",
});
```

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `instanceUrl` | string | — | Your Quackback URL. Required for npm. Baked into script-tag `sdk.js`. |
| `placement` | `"left"` \| `"right"` | `"right"` | Corner for the launcher and panel until admin config loads |
| `defaultBoard` | string | — | Board slug to filter the widget. Omit to show all boards |
| `launcher` | boolean | `true` | Set `false` to hide the default floating button |
| `locale` | string | Auto-detected | `"en"`, `"fr"`, `"de"`, `"es"`, `"ar"`, `"ru"`, `"pt-BR"`, `"zh-CN"`, or `"zh-TW"` |
| `identity` | object | — | Bundle identify into init. Production shape is `{ ssoToken }`. Omit for anonymous |

<Note>
**Admin → Settings → Widget → Layout** owns launcher position, label, and greeting. The admin position overrides `placement` after the widget loads its config.
</Note>

When `launcher` is `false`, open the panel from your own UI:

```js
Quackback.init({
  instanceUrl: "https://feedback.example.com",
  launcher: false,
});

document.getElementById("feedback-btn").addEventListener("click", () => {
  Quackback.open();
});
```

Script-tag calls use the same names: `Quackback("open")`, `Quackback("identify", { ssoToken })`.

## SDK methods

| Method | Description |
|--------|-------------|
| `Quackback.init(options)` | Create the launcher and iframe. `instanceUrl` required for npm. |
| `Quackback.identify(identity?)` | Attribute activity to a user. Pass `{ ssoToken }` for a signed-in user. Omit for anonymous. |
| `Quackback.logout()` | Clear identity. The widget stays visible in anonymous mode. |
| `Quackback.open(options?)` | Open the panel. Optional deep-link payload (see below). |
| `Quackback.close()` | Close the panel. |
| `Quackback.showLauncher()` / `hideLauncher()` | Show or hide the floating button. |
| `Quackback.metadata(patch)` | Attach session context to submitted feedback. Pass `null` to remove a key. |
| `Quackback.on(event, handler)` | Subscribe to an event. Returns an unsubscribe function. |
| `Quackback.off(event, handler?)` | Remove one handler, or all listeners for that event. |
| `Quackback.destroy()` | Tear down widget state and DOM. |
| `Quackback.isOpen()` | Whether the panel is visible. |
| `Quackback.getUser()` | The current identified user, or `null`. |
| `Quackback.isIdentified()` | `true` when a signed-in user is identified. |

### identify

See [Identify users](/widget/identify-users) for JWT claims and server examples.

```js
const { token } = await fetch("/widget-token").then((r) => r.json());
Quackback.identify({ ssoToken: token });
```

Calling `identify` again with a new token switches the active user.

### open

```js
Quackback.open();
Quackback.open({ view: "new-post", title: "Bug: page crashes on save", board: "bugs" });
Quackback.open({ view: "changelog" });
Quackback.open({ view: "help", query: "pricing" });
Quackback.open({ view: "chat" }); // Messages tab; `messages` also works
Quackback.open({ view: "tickets" });
Quackback.open({ postId: "post_01h..." });
Quackback.open({ articleId: "art_01h..." });
```

| Option | Type | Description |
|--------|------|-------------|
| `view` | `"home"` \| `"new-post"` \| `"changelog"` \| `"help"` \| `"chat"` \| `"messages"` \| `"tickets"` | Which surface to open. Default is home. |
| `title` | string | Pre-fill the post title with `view: "new-post"` |
| `board` | string | Board slug to pre-select with `view: "new-post"` |
| `query` | string | Help search query with `view: "help"` |
| `body` | string | Pre-fill the post body with `view: "new-post"` |
| `postId` | string | Deep-link to a post |
| `articleId` | string | Deep-link to a help article |
| `entryId` | string | Deep-link to a changelog entry |

`view`, `title`, and `board` are handled by the iframe today. `body`, `query`, `postId`, `articleId`, and `entryId` pass through and render as iframe support lands.

### logout, close, destroy

```js
Quackback.logout();
Quackback.close();
Quackback.destroy();
```

Call `logout` from your logout handler. Call `destroy` in SPAs when you unmount the host page.

## Single-page apps

Initialize once in a layout. Identify after auth resolves. Clean up on unmount.

```tsx
import { useEffect } from "react";
import { Quackback } from "@quackback/widget";
import { useAuth } from "@/hooks/use-auth";

export function FeedbackWidget() {
  const { user } = useAuth();

  useEffect(() => {
    Quackback.init({ instanceUrl: "https://feedback.example.com" });
    return () => Quackback.destroy();
  }, []);

  useEffect(() => {
    if (!user) return;
    fetch("/widget-token", { method: "POST" })
      .then((res) => res.json())
      .then(({ token }) => {
        Quackback.identify({ ssoToken: token });
      });
  }, [user]);

  return null;
}
```

<Tip>
The SDK queues `identify` until the iframe is ready. You do not need to wait for a `ready` event.
</Tip>
