# Self-Hosting

Quackback is designed to be self-hosted. Pick the deployment method that fits your setup.

## Choose your path

| Method | Best for | Time |
|--------|----------|------|
| [Railway](/self-hosting/railway) | Fastest start, no server needed | 2 min |
| [Docker](/self-hosting/docker) | Most deployments | 10 min |
| [Manual](/self-hosting/manual) | Full control, no containers | 30 min |

<Tip>
If you're not sure, start with Docker. It handles dependencies, migrations, and updates automatically.
</Tip>

## Before you start

Check the [system requirements](/self-hosting/requirements). You need PostgreSQL 14+ with pgvector, about 1 GB of RAM, and S3-compatible storage if you want file uploads. There is no Redis or other queue service to run: background jobs use PostgreSQL.
