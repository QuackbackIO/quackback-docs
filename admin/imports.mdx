# Import and export your workspace

Switching tools shouldn't mean starting from zero. Export your data from the tool you use today, fit it to Quackback's CSV template, and preview exactly what will change before anything touches your workspace.

## Overview

Open **Admin → Settings → Imports & exports**. From there you can:

- Import posts from a CSV exported from any tool
- Preview an import before committing
- Track import runs as they process in the background
- Export your whole workspace as one ZIP

## Import from a CSV

1. Click **Download template** and fill it in with your data. Each row needs `title` and `content`, plus `author_email` or `author_name`.
2. Pick the kind of export you're bringing in, then upload the file (up to 10 MB and 10,000 rows).
3. Review the preview: every row, the board, status, and author it maps to, and any boards, statuses, or tags the import will create.
4. Commit the import.

The template's columns are `title`, `content`, `status`, `tags`, `board`, `author_name`, `author_email`, `email_verified`, `vote_count`, `created_at`, and `source_id`. Statuses, boards, and tags that don't exist yet are created for you. An author with only a name becomes a name-only contact.

<Tip>
Fill in `source_id` with each item's ID from your old tool. Re-running the same file then updates those posts instead of creating duplicates.
</Tip>

Need comments, votes, and internal notes too? The command-line importer in the Quackback repository (`scripts/import`) reads separate CSV files for each and writes through the [REST API](/api/overview).

## Track import runs

Imports run in the background, so you can navigate away while a large import processes. **Import history** on the same page shows recent runs and their results.

## Export your data

**Export workspace data** builds one ZIP with your posts, comments, votes, users, companies, conversations, changelog, help center, and taxonomy. Download links expire after 7 days, and **Export history** lists recent exports.

To export a single board as CSV, open the board's **Data** tab in **Admin → Settings → Boards**. See [Import and export data](/admin/import-export#export-a-board-as-csv).

<Tip>
Need a full backup instead? Back up the PostgreSQL database and your object storage. See [self-hosting](/self-hosting/overview).
</Tip>
