# Import and export data

Bring your existing feedback with you, and take it out whenever you need it. Imports run from one place, **Admin → Settings → Imports & exports**. Each board can also export its own posts as CSV.

## Import posts from CSV

Imports run in the [Imports & exports](/admin/imports) hub, where you download the template, upload your file, and preview every row before anything changes. A board's **Data** tab (**Admin → Settings → Boards** → select a board → **Data**) has an **Import posts** row that links straight there.

### CSV format

| Column | Required | Format |
|--------|----------|--------|
| `title` | Yes | Text |
| `content` | Yes | Text or Markdown |
| `author_email` or `author_name` | One of them | A valid email, or a display name |
| `status` | No | Status name or slug. Missing statuses are created. |
| `tags` | No | Comma-separated. Missing tags are created. |
| `board` | No | Board slug. Missing boards are created. |
| `email_verified` | No | `true` or `false` |
| `vote_count` | No | Integer |
| `created_at` | No | ISO 8601, for example `2024-01-15T10:30:00Z` or `2024-01-15` |
| `source_id` | No | The item's ID in your old tool. Re-importing a row with the same `source_id` updates it instead of creating a duplicate. |

Files can be up to 10 MB and 10,000 rows.

```csv
title,content,status,tags,board,author_name,author_email,vote_count,created_at,source_id
"Add dark mode support","It would be great to have a dark mode option.","open","feature,ui","features","John Doe","john@example.com","5","2024-01-15T10:30:00Z","idea-123"
"Fix login timeout","Users are being logged out too quickly.","under_review","bug","bugs","","jane@example.com","2","","idea-124"
```

### Migrate from another tool

Export your data from your current tool as CSV, then map its columns onto the template:

- The idea or suggestion title → `title`
- The description or body → `content`
- The status → `status`
- The vote count → `vote_count`
- The original ID → `source_id`

Coming from a spreadsheet? Add the column headers above, use ISO 8601 dates, and save as UTF-8 CSV.

<Tip>
Import a few rows first and check them in the preview. With `source_id` filled in, you can fix the file and re-run it without creating duplicates.
</Tip>

## Export a board as CSV

1. Go to **Admin → Settings → Boards** and select the board
2. Open the **Data** tab
3. Under **Export**, click **Export CSV**

The download includes every post on that board:

| Column | Description |
|--------|-------------|
| `title` | Post title |
| `content` | Post content |
| `status` | Status name |
| `tags` | Comma-separated tag names |
| `board` | Board slug |
| `author_name` | Author display name |
| `author_email` | Author email |
| `vote_count` | Number of votes |
| `created_at` | Creation timestamp |

Exporting needs the **`post.export`** permission, which Owners, Admins, and Managers have. See [Roles and permissions](/admin/roles-permissions).

To export the whole workspace (posts, comments, votes, users, companies, conversations, changelog, and help center) as one ZIP, use **Export workspace data** in [Imports & exports](/admin/imports#export-your-data).

## Troubleshooting

### "Invalid CSV format"

- Save the file as UTF-8
- Quote fields that contain commas
- Keep the same number of columns on every row

### Dates import wrong

Use ISO 8601: `2024-01-15T10:30:00Z` or `2024-01-15`.

### Large imports

Imports run in the background, so you can leave the page. Check progress under **Import history** in [Imports & exports](/admin/imports#track-import-runs).
