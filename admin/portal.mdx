# Customize your portal

Portal settings now live under [Branding](/admin/branding). Identity, theme, the welcome card, and the portal's top navigation are all on one page with a live preview, so you can see changes before you save them.

Go to **Admin → Settings → Branding** (bookmarks to the old **Admin → Settings → Portal** page redirect there automatically).
